# 里程碑 B · 宠物窗与设置页

前置：A。产出：正式 SVG 形象 + 6 表情状态机 + 动画 + 拖拽 + 右键菜单 + 气泡 + 完整设置页。

## 研究结论 · 默认形象规格（来自参考图分析，原创绘制，不使用原图）

绿色圆球机器人（Haro 风格）：球形主体、球面分割线、无四肢。精确规格：

- **主体**：正圆，径向渐变 `#A8DB6B`(左上高光) → `#8DC63F`(主体) → `#6FAE33`(边缘) → `#5E9B2E`(底部)；左上叠加一个白色半透明椭圆高光（`opacity .45`，模糊感用两层椭圆模拟）。
- **分割线**：`#234D12`，`stroke-width 2`，`opacity .55`——顶部极点呈放射状的 3 条短弧线（只画球顶部 1/5 区域）+ 下半球一条水平环缝（在球心下方约 22% 半径处，弧线）。
- **极点凹槽**：顶部极点 3 个 4×2px 深色圆角矩形缺口。
- **眼睛**（默认/平常）：两只**竖椭圆**（宽:高 ≈ 1:1.6），中心分别位于球宽 35%/65%、球高 40% 处；填充 `#B03A3A`，描边 `#8E2F2F`（1.5px），微外倾 ±5°。
- **嘴**：`#1A1A1A`，`stroke-width 2.5`，圆头线帽。
- **画布**：viewBox `0 0 200 200`，球心 (100,104)，半径 78；地面阴影椭圆 `#000 opacity .12` 在 (100,190)。

## B1. 六表情差分（`src/renderer/pet/sprite.js`）

单一函数 `renderPet(svgHost, emotion)`：主体/分割线/高光/阴影为常量 SVG 字符串，眼睛与嘴按 emotion 查表替换，附加元素（红晕/汗滴/怒纹/思考点/泪滴）按需插入。全部用 path/ellipse 表达，规格如下（坐标基于上述画布）：

| emotion | 眼睛 | 嘴 | 附加 |
|---------|------|-----|------|
| normal | 默认竖椭圆 | 微上弯短弧（宽 56） | — |
| happy | 上弯弧线（`^` 形，stroke 3） | 大上弯弧（宽 70，深弯）+ 张口下弧填充 `#7A2E2E` | 两侧脸颊粉红椭圆 `#F2A6B0 opacity .5` |
| surprised | 放大圆眼（r 13，`#B03A3A` 填充 + r 4 白点高光） | 小椭圆 `o`（描边不填充） | 头顶两条短「!」线 |
| angry | 内斜切眼（上半被眼睑遮蔽：竖椭圆 + 覆盖主体色的斜矩形裁切，模拟`>` `<`形怒目） | 下弯弧（宽 60） | 头顶青筋：4 短线组成的十字菱形 `#C0392B` |
| thinking | 半垂眼睑（椭圆上半覆盖主体色矩形，留下半） | 短斜线（左低右高） | 右上方两个渐小圆点（思考泡）；一眼瞳孔上移 |
| sad | 半垂眼睑 + 眼角下垂 | 下弯波浪短弧（宽 50） | 一侧脸颊泪滴：`#6FB7E8` 泪形 path，带下落动画 |

自定义差分图模式：`sprites.json` 中槽位 `mode:"image"` 时，`renderPet` 渲染 `<img src="file://.../sprites/xxx.png">`（object-fit: contain，高度撑满 82%，垂直居中）；表情切换 = 换图（无过渡动画要求）。

## B2. 动画（pet.css + pet.js）

- **呼吸**：球体容器 `scale(1 → 1.035 → 1)`，3.2s 无限循环（transform-origin: bottom center）。
- **眨眼**：`pet.js` 每 3~6s 随机触发，眼睛元素 `scaleY(1→0.08→1)`，每次 140ms（CSS class `blink` + animationend 移除；image 模式跳过眨眼）。
- **表情切换弹跳**：emotion 变化时球体加 class `bounce`：`translateY(0 → -14px → 0 → -6px → 0)`，550ms。
- **点击**：单击球体 → 挥手气泡（随机吐槽/问候语 `pet.lines.js` 内置 12 条，如「今天也要加油哦～」）+ bounce。
- **睡觉**：托盘/菜单「休息一下」→ 停呼吸/眨眼，眼睑半闭（复用 thinking 眼睑），头顶 Zzz 文本动画；再次点击唤醒。

## B3. 拖拽与位置记忆

- 球体区域 `-webkit-app-region: drag`（气泡、菜单按钮区 no-drag）；拖动结束（`moved` 事件，轮询 `getBounds` 防抖 500ms）保存 x/y 到 `settings.windows.pet`。
- 拖动中禁用 bounce。窗口贴边检测：距屏幕边缘 <4px 时允许微吸附（x=0 等）。

## B4. 右键菜单（pet/menu.js）

球体 `contextmenu` → `ipc invoke('window:pet-menu')` → 主进程 `Menu.popup()`（保证层级），菜单项：

```
💬 聊天        → openWindow('chat')
📖 陪读        → openWindow('reader')
⏱ 时间统计     → openWindow('time')
📅 日程        → openWindow('schedule')
🎨 换装/形象    → openWindow('settings') 并广播 settings:tab {tab:'sprite'}
⚙️ 设置        → openWindow('settings')
───
😴 休息一下     → 睡觉开关
🚪 退出        → app.quit()
```

（陪读/时间/日程菜单项本里程碑就绪，窗口内容后续里程碑实现；点击开窗即算工作。）

**双击球体** → `openWindow('chat')`。**气泡组件**（bubble.js）：绝对定位于球体上方（球顶 <80px 时翻转到下方），圆角面板 + 小三角，最大宽 260px，纯文本（escape），队列化：多条按序各展示 `settings.pet.bubbleSeconds` 秒，点击立即关闭并显示下一条。

## B5. 情绪状态机（pet.js）

```js
setEmotion(emotion, { source, revertMs })  // source: 'chat'|'reader'|'schedule'|'idle'|'user'
```

- 优先级：`user`（点击/菜单）> `schedule`（提醒）> `reader` > `chat` > `idle`。
- 带 `revertMs`（默认 6000）的临时情绪到期回退到上一个持久情绪；chat/reader 的情绪视为持久直到下一次覆盖。
- 订阅 IPC `pet:emotion`（主进程 emotion.js 广播）；宠物窗是表情的**唯一渲染方**。
- 空闲小动作：每 10~20 分钟（活跃时段 9:00-22:00）随机 normal↔happy/thinking 切换 + 一条内置台词气泡。

## B6. 设置页（settings/index.html + app.js）

自绘标题栏（common/windows/ 通用组件：拖拽区 + 最小化/关闭，关闭=销毁窗口）。左侧竖排标签导航，右侧内容区。所有修改**即时保存**（input 事件防抖 300ms → `store:set`），无需保存按钮。

### ① 人设 tab
编辑 `persona.json → pet` 全部字段（name/tagline 文本框；appearance/personality/speechStyle/catchphrases/background/emotionalPatterns/taboos/thinkingLogic/customPrompt 为多行 textarea；language 下拉 中文/English/日本語/中英混合）+ `user.name`、`user.description`（对话对象信息）。空字段在 prompt 组装时自动省略（C 里程碑规则）。顶部实时预览：当前 system prompt 原文（折叠面板）。

### ② 形象 tab
6 槽位卡片（平常/开心/惊讶/愤怒/思考/悲伤）：每卡片 = 表情名 + 当前预览（SVG 直接渲染 / 图片缩略）+「上传图片」按钮（accept `.png,.jpg,.jpeg,.webp,.gif`）+「恢复默认」。
上传流程：`dialog:pick-file` → 主进程复制到 `sprites/{emotion}_{hash8}.{ext}` → 更新 `sprites.json`（mode:'image', file）→ 广播 `sprites:changed` → 宠物窗重渲染。恢复默认 = mode:'svg'。图片不大于 8MB，超限 toast 拒绝。页底：整体缩放滑杆（0.6~1.4，写 `settings.pet.scale`）。

### ③ 配色 tab
accent 预设色卡（5 个，见 A8）+ `<input type="color">` 自定义 + 明暗模式（浅色/深色/跟随系统）。改动即时广播 `theme:changed`，所有已开窗口立即生效（深色模式映射一组 `--dp-bg/--dp-panel/--dp-text` 深色值）。

### ④ API tab
表单：接口预设下拉（空=自定义；DeepSeek `https://api.deepseek.com/v1/chat/completions`·`deepseek-chat`；智谱GLM `https://open.bigmodel.cn/api/paas/v4/chat/completions`·`glm-4`；Kimi `https://api.moonshot.cn/v1/chat/completions`·`moonshot-v1-8k`；通义千问 `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`·`qwen-plus`；OpenAI `https://api.openai.com/v1/chat/completions`·`gpt-4o-mini`）+ endpoint/model 文本框 + API Key 密码框（写入时 safeStorage 加密）+ 高级参数折叠（temperature 0.8 / maxTokens 2048 / topP 0.9 / frequencyPenalty 0.3 / presencePenalty 0.3，滑杆）。「测试连接」按钮 → `llm:test`（发一条 maxTokens=8 的「你好」，返回延迟 ms 或错误）。

### ⑤ 指令 tab
`commands.json` 列表 CRUD：每行 = 指令词（如「打开微信」）+ 路径（文件选择按钮）+ 参数（可选）+ 类型自动识别（.exe/.bat/.html/.url/其他）+ 「试运行」按钮。行内校验：路径不存在时黄条提示。

### ⑥ 分类 tab
只读展示内置分类预设（E 里程碑实现 classifier 时同步补齐此表数据源）+ 用户规则列表（regex + 类别下拉，含自定义类别）+ 自定义类别管理 + 忽略列表（exe 名每行一条）。本里程碑只搭 UI 框架与 commands 式 CRUD，规则文件读写对接 E。

### ⑦ 日程偏好 tab
默认提前量三个数字输入（事件 60 / 任务开始 5 / 截止 120 分钟）、稍后提醒间隔（默认 10 分钟）、提醒提示音开关、系统通知开关、错过补报窗口（默认 24 小时）。读写 `settings.schedule`。

### ⑧ 关于 tab
版本号、数据目录路径 +「打开数据目录」按钮（`shell.openPath`）、使用说明摘要（各功能一句话）。
