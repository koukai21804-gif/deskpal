## A2. src/main/main.js

职责与顺序：

1. `app.setAppUserModelId('com.deskpal.app')`（Windows toast 通知必需，第一行）。
2. 单实例锁：`app.requestSingleInstanceLock()` 失败则 `app.quit()`；`second-instance` → 激活宠物窗 + 打开聊天窗。
3. `app.whenReady()` → 初始化 logger → store（建目录/默认值）→ 创建托盘 + 宠物窗 → 注册 ipc.js → 启动 theme.js 广播。
4. `window-all-closed` 不退出（宠物窗常驻 + 托盘）。托盘「退出」或 `app.on('before-quit')` → store.flush()、（后续里程碑的）服务 stop、`app.exit()`。
5. 防渲染进程崩溃：`webContents.on('render-process-gone')` 记日志并重建对应窗口。

托盘（`Tray` + `Menu.buildFromTemplate`）：图标用 `resources/icon.png`（先用 16×16 占位 png）。菜单项：`聊天 / 陪读 / 时间统计 / 日程 / 设置 / ── / 暂停时间监测(checkbox，写 settings.activity.paused) / 退出`。双击托盘 → 聚焦宠物窗。

## A4. src/main/preload.js

`contextBridge.exposeInMainWorld('deskpal', api)`，api 按域组织，通道全集与签名见附录 C。监听类方法统一模式：

```js
onLlmChunk(cb) { const h = (_e, d) => cb(d); ipcRenderer.on('llm:chunk', h);
                  return () => ipcRenderer.off('llm:chunk', h); }
```

invoke 类直接 `ipcRenderer.invoke(...)` 透传参数。**不暴露任何通用的 `send/on` 透传**（白名单式暴露）。

## A5. src/main/ipc.js

`registerIpc()`：逐条 `ipcMain.handle(通道, async (e, arg) => { try { return await handler(arg); } catch (err) { logger.error(err); throw new Error(err.userMsg || '操作失败：' + err.message); } })`。本里程碑先注册 store/theme/window 三组；后续里程碑在对应小节往此文件追加，不另开路由文件。

## A6. src/main/services/store.js

- `getDataDir()`：封装 `app.getPath('userData')`，启动时 ensure 全部子目录（见总纲 §5）。
- `get(name)` / `set(name, patch)` / `flush()`：内存缓存 + 深合并默认值（默认值表见附录 B 每个 schema 的 `defaults` 段）+ 防抖原子写。
- `config/` 下六文件 + `chats/ memory/ schedule/` 等的读写都走本模块（`store.get('settings')`、`store.set('settings', {...})` 按文件名为 key）。
- 原子写实现：`fs.writeFileSync(p+'.tmp', json); fs.renameSync(p+'.tmp', p)`。

## A7. src/main/services/fs-guard.js

```js
const READ_BLACKLIST = [
  /[\\/]Microsoft[\\/]Protect[\\/]/i,          // DPAPI 主密钥
  /[\\/]Microsoft[\\/]Crypto[\\/]/i,
  /NTUSER\.DAT/i, /[\\/]AppData[\\/]Local[\\/]Microsoft[\\/]Vault/i,
  /Login Data(\.json)?$/i, /Cookies(\.json)?$/i, /Web Data/i,  // Chromium 系
  /logins\.json$/i, /key[34]\.db$/i,           // Firefox
  /\.kdbx$/i,                                   // KeePass
  /id_(rsa|dsa|ecdsa|ed25519)/i, /\.ppk$/i,    // SSH 私钥
  /\.wallet$/i, /wallet\.dat$/i
];
function canRead(p)      // realpath 后逐一匹配黑名单，命中→false；否则 true
function canWrite(p)     // realpath 后必须以 userData 或 userData/temp 为前缀（大小写不敏感、统一反斜杠）
function readFileGuard(p)  // canRead 校验 → fs.readFileSync(Buffer)
function listDirGuard(p)   // canRead → fs.readdirSync withStats
```

`scripts/test-fs-guard.js`：独立 node 脚本，构造若干路径断言 canRead/canWrite（黑名单命中 false、userData 内 write true、桌面路径 write false 等），全部通过输出 PASS。里程碑 A 验收时运行。

## A8. src/main/theme.js

- 读取 `settings.theme`，`applyAll()` 向所有存活窗口 `webContents.send('theme:changed', theme)`。
- 预设主题（accent 名→色值）：`草地绿 #7DBE3C（默认）/ 海空蓝 #4A90D9 / 樱花粉 #E583B0 / 葡萄紫 #8E7CC3 / 落日橙 #E8A33D`。
- CSS 变量契约（`common/theme.css` 定义默认值，`theme:changed` 时 JS 重设 `document.documentElement.style.setProperty`）：

```
--dp-accent / --dp-accent-fg（按钮前景，自动黑或白）
--dp-bg 页面底 / --dp-panel 面板底 / --dp-border
--dp-text / --dp-text-muted
--dp-danger #d9534f / --dp-ok #5bb85b
--dp-radius 10px / --dp-shadow
```

前景色算法：accent 转 HSL，亮度 > 0.62 用深色文字 `#223` 否则白。

## A9. src/main/logger.js

`info/warn/error(msg)` → 同时 console 与 `logs/main.log` 追加 `HH:mm:ss.SSS [LVL] msg`（error 带堆栈）。超过 1MB 轮转为 `main.log.1`、`main.log.2`。
