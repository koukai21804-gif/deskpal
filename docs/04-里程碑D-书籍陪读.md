# 里程碑 D · 书籍陪读（as-built）

前置：C。产出：`services/documents.js` + `services/reading.js` + 陪读窗（书库/生成进度/放映）。

## D1. 文档解析（services/documents.js）

`parse(filePath) → { text, meta }`，上传前经 fs-guard 校验读权限。

| 格式 | 方案 | 备注 |
|------|------|------|
| txt/md/markdown | Buffer 直读 | BOM/UTF-8 优先，出现大量 U+FFFD 时 iconv-lite GBK 兜底 |
| pdf | pdfjs-dist 3.x legacy build（CJS） | 逐页 getTextContent，页间插 `<!-- p:N -->` 标记；最多 500 页 |
| docx | mammoth extractRawText | |
| doc | word-extractor | |

- 清洗：去 URL/DOI、断词连字符、>3 连续空行折叠；上限 30 万字符（截断时 meta.truncated 标记）
- 扫描版检测：平均每页 <50 字符 → 抛「疑似扫描版，请换文字版（暂不支持 OCR）」
- 文字 <200 字符拒绝陪读

## D2. 两阶段生成（services/reading.js）

- **阶段一 大纲**：`prompts.readingOutlinePrompt`（结构分析师人格，temp 0.3）→ JSON `{sections:[{title,summary,keyPoints[],mood,quizIntent}]}`，3-6 节，schema 校验失败即抛错
- **阶段二 逐节 flow**：`prompts.readingFlowPrompt`（宠物本人人格，temp 0.6）→ JSON 数组，帧类型：
  - 台词 `{t:"d", e:"情绪键", x:"台词≤120字", bb:"黑板markdown"}`
  - 测验 `{t:"q", q, o:[3选项], c:正确下标, f:[3反馈]}`
- 原文切片：第 i 节取 `[per*i-300, +4500)` 字符窗口喂给 prompt
- **校验与重试**：validateFlow 检查帧数≥5/测验恰好 1/字段完整性；失败带错误信息重试 1 次；再失败给最小可播兜底帧（保证流程不中断）
- **帧编译**：d/q → 线性 frames `{id:"f{i}_{n}", type:dialogue|quiz, sectionId, mood, text|q/options/correct/feedback, bb}`；quiz 选项反馈后自然汇合到下一帧
- 每节完成即写盘（进度可恢复）；进度事件 `reader:progress {bookId, stage: outline|flow|done|error|cancel, pct, message}`
- 取消：`reader:cancel-generate` 置 canceled 标志，状态回 `parsed`

## D3. 放映（reader/app.js）

- 左栏 galgame 区：宠物 SVG 头像（随帧 mood 切换 + `pet:emote` 联动全局宠物窗）、说话人名、打字机（速度随文本长度自适应，点击对话框立即完成）、旁白斜体样式、测验三选项（对/错着色 + 反馈条 + 表情联动）、自动播放（打字完 2.2s 自动下一帧，测验答题后 2.6s）、上一帧回看
- 右栏黑板：bb 经 md.js（marked+KaTeX）渲染，空则保持上一帧内容
- 帧推进即 `reader:save {cursor}` 落盘，续读从 cursor 恢复

## D4. 举手提问（侧信道）

- `reader:ask {bookId, question}` → 关键词重合度给 800 字符块打分取 top3 原文 → `readingQAPrompt`（明确"不改动剧本状态"，要求 [C1] 式引用，允许"书中没有涉及"）
- 流式回推 `reader:qa-chunk` / `reader:qa-done`；问答（含提问时的帧位）追加进存档 qa[]，不移动 cursor

## D5. 存储

- `books/{bookId}.json`：{ id, meta, text, createdAt }
- `library/{bookId}.json`：{ id, title, meta, status: parsed|generating|ready|error, error, outline, sections, frames, qa[], cursor, createdAt, updatedAt }
