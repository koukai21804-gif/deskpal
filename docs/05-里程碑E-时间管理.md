# 里程碑 E · 时间管理（as-built）

前置：C。产出：`services/activity/{watchers,tracker,classifier,stats,report}.js` + 时间页 + 标注窗。ActivityWatch 方案复刻：API 轮询，无全局钩子。

## E1. watchers.js（koffi FFI）

- DLL：user32（GetForegroundWindow/GetWindowTextW/GetWindowThreadProcessId/GetLastInputInfo）、kernel32（OpenProcess/QueryFullProcessImageNameW/CloseHandle/GetTickCount）；全部以 buffer 指针传参，x64 下 stdcall 兼容
- 1s 轮询前台窗口 → `{pid, exePath, exeName, title}`（无标题窗口如桌面忽略）；5s 轮询空闲（GetTickCount - dwTime，处理 32 位回绕）
- 活跃→空闲（≥idleThresholdSec，默认 180s）：回调时刻 = now - idleMs（真实离开点）；空闲→活跃：恢复记录
- `setPaused` 停/启计时器并 flush（托盘「暂停时间监测」/时间页按钮共用）；koffi 不可用时降级为禁用并记日志

## E2. tracker.js（心跳合并 → 按天 JSONL）

- 会话 = exe+title 相同的连续心跳；切换即闭合上一条 `{type:"app", app, exe, title, start, end, dur}` 追加到 `activity/YYYY-MM-DD.jsonl`
- 空闲区间写 `{type:"afk", start, end, dur}`（>5s 才记）
- **空闲归来**：当天存在未分类应用 → 广播 `pet:bubble {kind:'ask-label', text:"今天开启的部分应用..."}` + `activity:idle-back`；**每天最多问一次**（askedIdleBack 按天记忆）

## E3. classifier.js

优先级：忽略表 → 用户标注 appLabels → 用户规则（正则最长匹配，匹配 exe 或标题）→ 内置 exe 预设（约 50 个常见应用：IDE/办公→工作，游戏/音乐/视频→娱乐，微信/QQ/Discord→社交 等）→ 内置标题规则（浏览器细分：bilibili/YouTube→娱乐，github/知乎/知网→学习，淘宝/京东→其他，微博→社交…）→ unknown。返回 `{category}` / `{unknown:true}` / `{ignore:true}`。

## E4. stats.js

- `stats(range today|week)`：读 1/7 天 JSONL，**读取时实时分类**（标注后历史数据自动重新归类）；输出 totalMin/afkMin/byApp（含 topTitle/titles）/byCategory/byHour[24]/unknownCount
- `unknownApps()`：今天无类别的应用清单（标注窗数据源）
- `saveLabels([{app, category}])`：写 appLabels，新类别自动加入类别表，广播 time:changed

## E5. report.js（AI 报告）

聚合 JSON（分类/Top12 应用/最忙时段）+ 人设口吻 prompt（要求 markdown 三节 + 情绪标签）→ 流式 `report:chunk`/`report:done` 推送到时间页，情绪标签剥离后驱动宠物表情。

## E6. 时间页 / 标注窗

- 时间页：今日/本周切换、四张统计卡、未知应用黄条入口、24h 纯 CSS 柱状图、类别占比条、应用排行（未标注黄标）、AI 报告流式渲染区；60s 自动刷新 + time:changed 事件刷新
- 标注窗（label）：列出未知应用（名称/今天时长/窗口标题例）→ 下拉选类别（5 预设 + 自定义输入）→ 保存即重算
